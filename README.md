# GitHub User Finder

A simple Python project that uses the GitHub API to find and display information about a GitHub user.

## Features

- Search for a GitHub user by username
- Display username
- Display name
- Display followers
- Display following
- Display public repositories

## Requirements

- Python
- requests library
- Internet connection

## How to Run

Install the required library:

pip install -r requirements.txt

Then run:

python github_user.py

The program will ask for a GitHub username.

## Technologies

- Python
- HTTP
- REST API
- GitHub API
- JSON
